Export / import this internet

Download saves every cached page as a real, plain .html file, each one named for its site and placed inside the folder name above (a browser download can't be pointed at an arbitrary drive letter, so it lands in your normal Downloads folder). Upload reads every .html file out of a folder you pick and caches it as a visited page — the original files aren't needed afterward.

Domain templates

Point this at a folder of your own .html files — one per domain (e.g. instagram.com.html), or a subfolder per domain with an index.html inside — and Latent will use that file as the real header/footer/stylesheet for that domain instead of inventing one, the same way it reuses a site's own shell. Saves tokens and speeds up every page on that domain. Browsers won't let a webpage read a typed-out path like D:\Projects\oldinternet without you picking it — use the button below to grant access.
